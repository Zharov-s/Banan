# Банановый апсейл

Игровой дашборд конкурса МПП по допродажам модификаторов при продлении поставок.

- Данные читаются напрямую из Google Sheets и обновляются раз в минуту.
- Высота подъёмника - доля продлений с допродажей. Размер банана над головой - средний чек модификатора.
- Сборка не нужна: статический сайт на ES-модулях.

```bash
npm start   # http://localhost:4173
npm test    # проверка расчёта рейтингов
```

Интерактивные элементы «Sound toggle with the scroll mixer» и «Course card to course page transition» адаптированы из библиотеки [Animorio](https://animorio.com) по её лицензии. Анимации - GSAP.
